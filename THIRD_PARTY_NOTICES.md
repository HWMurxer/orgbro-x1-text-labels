# Third-party components

The source code uses these separately maintained Python packages:

- Pillow — image rendering
- pySerial — serial-port communication

The optional Windows build process also uses PyInstaller.

These packages are not relicensed by this repository. Distributors of compiled
binaries should include the license texts shipped with the exact package
versions used for the build.

No source code from XEasyLabel, TiMini-Print, or the printer firmware is
included.
